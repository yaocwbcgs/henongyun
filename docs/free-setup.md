# 零成本接入指南

四项待接入服务里，**两项可以真正免费跑起来**（邮件、识别试用额度），**两项没有免费的真实通道**（在线支付、行情 API）。下面给出每一项的最低成本路径、精确参数与验证方法。

| 能力 | 免费程度 | 成本 | 耗时 |
| --- | --- | --- | --- |
| 找回密码邮件 | 完全免费 | 0 元 | 5 分钟 |
| 病虫害识别 | 注册送 100 次，之后付费 | 0 元起，超出 €0.05/次 | 10 分钟 |
| 在线支付 | 无免费真实通道 | 通道费 0.6% 起 | 需营业执照 |
| 行情采集 | 无开放 API | 0 元（人工录入） | 录入即用 |

## 1. 邮件：QQ 邮箱 SMTP（完全免费）

个人 QQ 邮箱即可，无需企业认证、无需域名。腾讯官方说明：SMTP 服务与授权码均免费。

### 步骤

1. 浏览器登录 [mail.qq.com](https://mail.qq.com)，点右上角「设置 → 账号与安全」。
2. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务」，开启 **SMTP 服务**。
3. 按提示用绑定手机发送短信验证，通过后页面给出 **16 位授权码**（只显示一次，先复制）。
4. 编辑 `server/.env`：

```ini
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=你的QQ邮箱@qq.com
SMTP_PASS=刚才那16位授权码
MAIL_FROM=禾农云 <你的QQ邮箱@qq.com>
```

5. 重启服务，进入后台「服务接入 → 邮件」点「连通性检查」，应返回 `ok: true`。
6. 到 `/forgot-password` 输入一个真实邮箱，确认收到验证码并完成重置。

### 注意

- 密码栏填**授权码**，不是 QQ 登录密码；改 QQ 密码会让授权码失效，需重新生成。
- 端口用 **465 + SSL**。25 端口在国内云主机与运营商侧大面积封禁，不要用。
- `MAIL_FROM` 建议与 `SMTP_USER` 一致，否则容易被判为伪造发件人。
- 个人邮箱有每日发信量限制（数百封量级），适合早期；量上来后换腾讯企业邮免费版（需域名）或 Brevo / Resend。

### 其他等价免费选项

| 服务 | 免费额度 | 适用 |
| --- | --- | --- |
| 163 邮箱 | 免费，`smtp.163.com:465` | 与 QQ 邮箱同理 |
| 腾讯企业邮免费版 | 免费，需自有域名 | 有域名、要专业发件地址 |
| Brevo | 300 封/天 | 海外可达，国内延迟不稳 |
| Resend | 100 封/天 | 需域名验证，国内可达性一般 |

## 2. 病虫害识别：Kindwise 注册送 100 credits

Plant.id 的运营方 Kindwise 提供免费试用额度，**注册即送 100 credits，1 次识别扣 1 credit**，无需绑卡即可开始。

### 步骤

1. 打开 [admin.kindwise.com/signup](https://admin.kindwise.com/signup) 注册账号（邮箱即可）。
2. 登录后在 **API keys** 页面复制密钥。
3. 写入 `server/.env`：

```ini
RECOGNITION_PROVIDER=plantid
PLANTID_API_KEY=你的密钥
PLANTID_BASE_URL=https://api.plant.id/v3
```

4. 重启服务，后台「服务接入 → 病虫害识别」点「连通性检查」。
5. 到 `/diagnose` 上传一张真实病叶照片，确认结果页出现「识别来源：Plant.id v3 Identification API」与模型版本。

### 额度与成本

- 免费 100 次，够完成联调、验收与初期演示。
- 用完后按量付费：1000 次起购，€0.05/次（€50 起）；800 万次以上可降到 €0.012/次。
- 免费额度用尽时，接口会返回 401/402，系统会把任务标记为失败并提示原因，可一键转人工复核——不会伪造结果。

### 额度用尽后的低成本选择

| 方案 | 成本 | 说明 |
| --- | --- | --- |
| 转人工复核 | 0 元 | 已实现：识别失败后提交农技咨询工单，由农技人员回复 |
| 只对高价值作物调用 | 按次 | 在业务上限制免费额度只用于番茄、黄瓜等主力作物 |
| 本地开源模型 | 0 元 | PlantVillage 等数据集训练的模型可离线推理，但只覆盖实验室条件叶片，田间准确率明显下降，需标注「辅助初筛」 |
| 国内云厂商定制模型 | 有免费额度 | 百度 EasyDL、腾讯云 TI 平台有试用额度，需企业认证，且要自行训练 |

> 平台不对识别准确率作承诺。任何方案的输出都应标注来源与概率口径，低置信度引导人工复核。

## 3. 在线支付：没有免费的真实通道

这一点必须说清楚：**真实收款不存在零成本方案**，通道费是刚性成本。Stripe 官方支持地区列表中**不包含中国大陆**，大陆营业执照无法直接开户。

### 零成本跑通全流程：线下结算（已内置）

不配置任何支付密钥时，商城订单仍可完整走完：

```
下单（扣库存）→ 商家「确认线下收款」→ 填写运单发货 → 买家确认收货 → 售后 / 评价
```

这是真实的业务模式（货到付款、转账、微信收款后人工确认），不是模拟支付。后台支付记录会标注 `provider=offline`，不会伪装成在线支付成功。

### 要真在线收款时的选择

| 通道 | 开户门槛 | 费率 | 说明 |
| --- | --- | --- | --- |
| 支付宝当面付 / 手机网站支付 | 营业执照（个体户可） | 约 0.6% | 国内最现实，需签约开放平台 |
| 微信支付 Native / JSAPI | 营业执照 + 商户号 | 约 0.6% | 需认证服务号或小程序 |
| Stripe | 香港 / 美国 / 英国公司 | 2.9% + $0.30 起 | 大陆主体不可直接开户，注册海外公司成本数千元 |

接入任一通道时，只需替换 `server/src/services/payments.js` 中的 `createCheckout`、`verifyStripeSignature`、`refundPayment` 三个函数，订单与库存逻辑无需改动。

> 沙箱/测试模式通过，不代表生产支付已开通。上线前必须用真实小额订单验证支付、退款与重复回调。

## 4. 行情：官方数据公开可查，但没有开放 API

农业农村部「全国农产品批发市场价格信息系统」（[pfsc.agri.cn](https://pfsc.agri.cn)）数据公开、免费查看，但**未提供开放接口**，程序直接请求会返回 403。

### 免费合规做法：人工录入 + CSV 导入（已内置）

1. 后台「行情采集 → 新增来源」，建一个「人工录入」来源（例如：全国农产品批发市场价格（人工录入））。
2. 从官方页面查看当日行情，在「录入一条行情」逐条填写，或点「填入示例格式」后按 CSV 批量粘贴。
3. 每条记录必须填写：作物、规格、省份、市场、价格、单位、**报价口径**、**采集时间**。
4. 在「待审核行情」逐条通过后，前台才会展示，并自动带出来源、采集时间与口径。

CSV 列顺序：

```csv
crop,variety,spec,grade,province,market,price,unit,quoteBasis,collectedAt
番茄,硬粉,中等果,一级,山东省,寿光农产品物流园,4.20,元/公斤,中等规格批发价,2026-11-05 08:00:00
```

### 想自动采集时

- 需先获得数据方的书面授权或商务接口（第三方行情 API 多为 0.1–1 元/次，不是免费）。
- 拿到接口后填写 `MARKET_API_URL`、`MARKET_API_KEY`，采集结果仍进入「待审核」队列，不会直接展示。
- 不建议抓取官方页面：既不稳定（有反爬），也可能违反网站使用条款。

## 6. 常见问题

**QQ 邮箱报「535 Authentication failed」**：用的是 QQ 密码而不是 16 位授权码，或授权码已被改密作废。

**连接超时**：端口填了 25；改用 465 + `SMTP_SECURE=true`。云服务器还需确认出站 465 未被安全组拦截。

**识别返回 401**：密钥未生效或复制时带了空格；到 Kindwise 后台重新生成。

**识别返回 402 / quota**：100 次免费额度用尽，需购买 credits 或转人工复核。

**Stripe 开户被拒**：大陆主体不在支持地区，需海外公司主体；国内业务建议直接接支付宝/微信。

**行情接口 403**：官方站点未开放 API，属预期；使用人工录入或申请授权接口。
