## 四、已知限制与风险

1. **SQLite 单写者模型**：适合单机中小规模。高并发写入场景建议迁移 PostgreSQL（仓储层已集中，改动范围可控）。
2. **SSE 单进程**：多实例部署时需替换 `server/src/realtime/hub.js` 为 Redis 发布订阅。
3. **演示数据**：`DEMO_SEED=true` 会写入带「演示」标识的店铺与商品。生产必须关闭，否则会与真实经营者混淆。
4. **图片存储**：当前为本地磁盘。容器化部署需挂载持久卷；如需对象存储，替换 `server/src/services/storage.js` 的写入与 URL 生成即可。
5. **支付币种**：Stripe 对部分币种有结算限制，上线前需确认商户主体与结算币种。
6. **未做压力测试**：当前仅验证功能正确性与并发预约的唯一性，未进行大规模压测。
